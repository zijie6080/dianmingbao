# 点名宝 UI/UX 第一批改版

基线：919051f456f700df915bedb8934047c1463b12a0。依据产品诊断报告 D0–D4，保留现有蓝色品牌、导航、业务流程和组件库。

## 本批实际完成

- 课程页压缩封面与大头像，标题与课程标记并排。
- 进行中签到状态前置；按钮区保留唯一恢复操作，使用“继续签到”文案。
- 活跃摘要为打开页面时的数据，明确引导打开面板查看最新进度，不冒充实时更新。
- 出勤趋势移到记录后方，保留现有统计计算、查询和导出。
- 工作台去掉重复的迷你趋势与进度条、焦点区点阵；保留课程人数、统计及入口。
- 手机导航复用已有 Base UI Dialog，提供焦点管理、Esc关闭和关闭后焦点恢复。
- 签到时长用原生单选控件，支持键盘方向键，保留默认值、记忆与提交逻辑。
- 名单突出姓名、弱化学号并允许换行；行操作触控区域增大。
- 登录、注册、找回密码共享集中式表单布局，品牌统一链接首页。
- 注册姓名用途改为持续可见的辅助文字，输入与按钮尺寸改善。
- 学生页调整表单尺寸，不改姓名匹配、提交、票据和回执实现。

## 合并前验收

1. 测试环境数据库必须独立，不能直接使用可能继承生产数据库的 Vercel Preview。
2. 在1440px与390px宽度检查课程、工作台、名单、学生与认证页，覆盖空数据、长姓名/学号和深色模式。
3. 检查手机导航的Tab焦点、Esc、关闭后焦点返回；检查时长方向键选择。
4. 实际操作投屏、+1分钟、提示音与快捷键，确认无重复创建、遮挡和滚动异常。
5. 检查同一测试数据下改版前后人数、状态、导出一致。
6. 以上通过后再批准生产发布。本分支是草稿，不能宣称已上线。
